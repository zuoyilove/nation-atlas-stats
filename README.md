NationAtlas — a national statistics site: population, GDP, life expectancy and development for 18 countries, with real 2024 figures from the World Bank, IMF and UN, each with its source and year. Overview with charts, a profile page per country (10-year trends), side-by-side comparison, and a sortable rankings table. Static files only, no build step, no network requests, works on desktop and phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — Overview, Countries, Compare, Rankings and About are all hash routes in `app/`.
